# 📄 Portfólio de Testes Manuais – Lucas Custodio

Este repositório contém meu portfólio de testes manuais com três exemplos reais aplicados em aplicações Web e Mobile.

## ✅ Conteúdo:

1. **Login com credenciais válidas** – Mercado Livre (Web)
2. **Cadastro com e-mail inválido** – iFood (Mobile)
3. **Pesquisa de produto inexistente** – Amazon (Web)

Cada teste inclui:
- Pré-condições
- Passo a passo
- Resultado esperado

## 💡 Objetivo
Demonstrar minha experiência prática com testes manuais, documentação clara e foco em qualidade de software.

## 📌 Sobre mim
Tenho grande interesse em: Desenvolvimento de Sistemas, Full Stack, com interesse em QA Qualidade de Software, testes e desenvolvimento.
